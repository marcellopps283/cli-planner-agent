# Slide Outline

## Slide 1 - Blueprint Planner-Agent

Terminal AI planning harness for multi-model coding workflows.

## Slide 2 - Problem

AI coding tools execute quickly, but poor upfront planning creates context drift, duplicated work, weak task boundaries, and wrong model choices.

## Slide 3 - Solution

Blueprint runs an investigative planning chat, validates requirements, routes tasks to exact models, and generates `.blueprint/` handoffs for worker agents.

## Slide 4 - Agentic Workflow

1. Onboard project, providers, models, reasoning effort.
2. Brainstorm and fill missing requirements.
3. Preview dependency graph and model assignments.
4. Generate architecture, task XML, and integration guide.

## Slide 5 - Why It Matters

Blueprint saves tokens, reduces planning mistakes, and makes AI-assisted development auditable before workers start changing code.

## Slide 6 - Next

MVP 1.0 is planner-only. Version 2.0 becomes a supervisor that can run Codex, Claude Code, Gemini CLI, or other workers directly.
